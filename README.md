# Project Overview

This project shows a text-based game that you can play in the terminal written in Python. It allows you to choose one of 4 unique hero classes to battle The Evil Wizard. It gave a lot of practice working with inheritance and loop logic.

## Steps for viewing this project

1. Clone or download the repository to a folder in a chosen location.
2. Open the file in an IDE or text editor of your choosing for review.
3. You may run and play this game in the terminal by running it with the python command (assuming you have installed python).
4. Defeat The Evil Wizard
